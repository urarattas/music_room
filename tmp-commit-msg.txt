fix(ci): 移除 metadata-action 标签里的行尾注释，解决 Invalid event 报错

根因
docker/metadata-action 解析 tags 时，会先把整行按逗号切分再按等号切分，
**不会剥离井号注释**。所以

    type=ref,event=branch            # master -> master

会让 event 的值变成 "branch            # master -> master"，
校验时对不上 RefEvent.Branch，于是抛
Error: Invalid event for type=ref,event=branch

修复
- 把所有标签说明移到独立注释行，tags 块内只保留纯粹的标签表达式
- 确认 labels 块不受影响：它不做等号切分，整行原样使用（已查源码验证）

测试
- 新增 test/metadata-action.test.js：6 项
  复刻了 metadata-action 的 src/tag.ts 解析逻辑（含 RefEvent/Type 枚举
  与 Invalid event 校验），从而能在本地验证工作流里的标签写法：
  - 证明「行尾注释会导致解析失败」这个坑真实存在
  - 校验工作流的 tags 不含井号字符
  - 校验每个标签都能被正确解析
  - 校验标签类型齐全（ref/semver/raw/sha，ref 含 branch/tag/pr 三种事件）
  - 校验 labels 均为 key=value 形式
